# Getting Started

## Installation

```bash
pip install pytest-tattletale
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv add pytest-tattletale
```

## Basic Usage

```python
from pytest_tattletale import add

result = add(1, 2)
print(result)  # 3
```
